Valuation Parameters

Our model maps non-linear hedonic parameters to historical transactions. Each variable contributes to the predictive baseline:

  • Square Footage: Captures spatial volume, finished ceilings, and primary living envelope.
  • Bedroom Count: Reflects utility for single occupants, families, and dual-purpose rooms.
  • Bathroom Count: Models plumbing fixtures, en-suite accommodations, and luxury density.
  • Location Index: Calibrated per-district land valuation and urban accessibility.

Architecture Guide

System Design & Operations

Comprehensive developer reference for running pipelines, managing DVC data, and triggering automated tests.

1. Reproducing the DVC Pipeline

DVC tracks dependencies between raw data, preprocessing, and model training:

# Execute full pipeline
dvc repro

# Inspect metrics recorded by training stage
dvc metrics show

2. Starting the FastAPI Backend

Run Uvicorn directly from the workspace root:

uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

3. MLflow Local Dashboard

Inspect all hyperparameter experiments and model artifact runs:

mlflow ui --port 5000

4. Automated Test Suite

Execute unit and integration tests with pytest:

pytest tests/ -v
